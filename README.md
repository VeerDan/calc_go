## Usage

```
В данном разделе описана модель использования сервиса
```
1. Скачайте проект
2. Разместите файлы проекта в одной папке
3. В терминале перейдите в эту папку (cd ..., где вместо ... вставьте путь)
4. go run ./cmd/main.go
5. Можете обращаться к сервису запросами HTTP с методом POST, данными типа json вида '{"expression":"example_expression"}' в теле запроса

```
Некоторые замечания по поводу работы данной версии проекта:

1. На данном этапе проекта, отрицательные числа не поддерживаются. Для записи отрицательных чисел использовать выражение вида "(0 - a)"

2. Пробелы в example_expression никак не влияют на работу сервиса.

3. Для записи десятичной дроби использовать ".". Знак "," не поддерживается.

4. В example_expression недопустимо использование любых символов, кроме цифр десятичной СИ, знаков операций умножения ("*"), деления ("/"), сложения ("+"), вычетания ("-") и приоритезации ("(" и ")"), а также знак разделителя десятичной дроби ".".

5. В проекте реализовано логгирование (подробнее про логирование рассказано в разделе logging.
```

## Documentation

```
В данном разделе описана структура проекта
```
Проект состоит из трёх папок: cmd, internal, pkg. В папке cmd содержится единственный файл main.go (package main), который содержит функцию main, создающей и запускающей в теле application.  
  
internal содержит в себе подпапку apllication, в которой содержаться два файла: application.go и application_test.go (package application). application.go содержит функции для работы с сервером. application_test.go предназначен для тестирования сервера.

pkg содержит в себе подпапку calculation, в которой содержится три файла (package calculation): calculation.go, calculation_test.go, errors.go. В calculation.go описаны функции для подсчёта арифметических выражений, в calculation_test.go содержатся тесты для отладки кода calculation.go, в errors.go - описание ошибок, возникающих при подсчёте результата.


## Errors
```
В данном разделе представлены ошибки, которые могут возникнуть при подсчёте арифметического выражения и описанные в "./pkg/calculation/errors.go".
```
| Ошибка | Описание | Примеры выражений |
| :---:  | :---:    | :---:            |
| ErrInvalidExpression | Неправильный формат example_expression: несоответсиве скобок,  несоотвествие операций | "-1+2"; "/1*2", "(1+2", "1+2(3*4)"|
| ErrExternalSymbols | Использование недопустимых символов | "2!", "3?", "4A" |
| ErrDivisionByZero | Ошибка деления на ноль | "1/0", "100/(2-2)" |
| ErrEmptyExpression | Пустое выражение | "", " " |

## Logging
```
В данном разделе описано как работает логгирование в проекте.
```
Логгирование ответов сервера реализована в теле CalcHandler. Логгирование времени ответа сервера реализовано с помощью обёртки CalcHandler в TimeMiddleware. Логи записываются в os.Stdout.

На один запрос к серверу приходится два лога в соедующем порядке:

1. Лог уровня Info с результатом, при условии, что возвращён статус-код 200. В ином случае (статус-коды 422 и 500) лог уровня Error с ошибкой. В обоих логах записан статус-код ответа.
2. Лог уровня Info c временем ответа сервера.
---
| Тело запроса | Лог |
| :---: | :---: |
| {"expression": "100/0"} | 2024/12/20 15:36:59 ERROR error: division by zero; status_code: 422<br>2024/12/20 15:36:59 INFO Время ответа сервера: 1.219083ms |
| {"expression": "-100.1"} | 2024/12/20 15:50:05 ERROR error: invalid expression; status_code: 422<br>2024/12/20 15:50:05 INFO Время ответа сервера: 1.090917ms |
| {"expression": "1000/(1+2*4)"} | 2024/12/20 15:54:22 INFO result: 111.11111111111111; status_code: 200<br>2024/12/20 15:54:22 INFO Время ответа сервера: 94.25µs |
| {"expression": "2+4"} | 2024/12/20 15:55:12 INFO result: 6; status_code: 200<br>2024/12/20 15:55:12 INFO Время ответа сервера: 68.375µs |
---
